# TypeClip

macOS 菜单栏小工具：按 **⌃⌘V**，把剪贴板里的文本**逐键敲入**当前应用。

专为「禁止粘贴」的场景而生——堡垒机、远程桌面、虚拟机、某些网页终端里 ⌘V 被禁用或剪贴板与本地不互通时，TypeClip 直接模拟键盘输入，把内容一个字符一个字符敲进去。

## 特性

- **键码优先注入 + Unicode 回退**：先用 UCKeyTranslate 按当前键盘布局反查键码、真实地合成按键事件，反查不到才回退 Unicode 直接注入，最大化远程端的识别率（`#`、`@` 这类 Shift 符号不会退化成裸数字）
- **修饰键加固**：修饰键段保持（连续同修饰字符整段按住）、最小 100ms 修饰键延迟、发字符前按 flagsState 自愈补发，适应远程端对修饰键登记慢的问题
- 两个可调维度：「**敲入速度**」（字符间隔、按住时长、随机抖动、修饰键延迟全部由它派生）与「**输入法**」三态（不动 / 触发时切英文 / 切英文并在结束后恢复）
- 敲入过程中再按一次 ⌃⌘V = 中断
- 开机自启、剪贴板内容预览、面板实时显示进度
- 日志默认不含剪贴板明文（`~/Library/Logs/TypeClip.log`）

## 安装

1. 从 [Releases](releases) 下载 DMG，把 TypeClip.app 拖进「应用程序」
2. 首次打开请**右键 → 打开**（本包为 adhoc 签名、未公证，直接双击会被 Gatekeeper 拦下）
3. 授权：系统设置 → 隐私与安全性 → 辅助功能 → 开启 TypeClip（菜单面板顶部会有橙色提醒和直达按钮）
4. 复制文本 → 切到目标窗口（远程桌面/终端）→ 按 **⌃⌘V**

要求：macOS 13+，Apple 芯片（arm64）。

## 从源码构建

只需 Xcode Command Line Tools，不需要完整 Xcode：

```sh
./build.sh dev       # 开发构建：含诊断钩子（分布式通知驱动、注入诊断），仅本机调试用
./build.sh release   # 发布构建：编掉全部诊断钩子，可分发（脚本会校验二进制中无钩子残留）
./make-dmg.sh        # 打一个带拖拽引导的 DMG（自动先做 release 构建）
```

## 已知限制

- 仅构建 arm64 slice（Apple 芯片）
- adhoc 签名、未公证：他人首次打开需要右键「打开」绕过 Gatekeeper；替换安装后需在「辅助功能」里重新授权
- 如果远程端完全拦截合成键盘事件，TypeClip 无法绕过（那是目标系统的主动防护）
